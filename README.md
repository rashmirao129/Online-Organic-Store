# Online-Organic-Store
Online organic store is a web-application which reduces the manual work for managing details of the customers, stocks and order for organic vegetables and fruits. 
## 🛒 Online Organic Store
### 📌 Overview
A web-based e-commerce application for buying 
organic vegetables and fruits online. Built as 
part of MCA curriculum at NMAMIT Nitte (Sep 2021).
### 🎯 Objective
Reduce manual work for managing customer details, 
stocks and orders for organic vegetables and 
fruits through a digital platform.
### ✨ Features
- 🔍 Product search functionality
- 🛍️ Browse organic vegetables and fruits
- 👤 Customer information management
- 📦 Order management system
- 📊 Stock management
