# Online-Organic-Store
Online organic store is a web-application which reduces the manual work for managing details of the customers, stocks and order for organic vegetables and fruits. 
## 🛒 Online Organic Store
An e-commerce web application for buying organic vegetables and fruits online — built with MongoDB, Node.js, Bootstrap, HTML, and CSS.
### 📌 Project Overview
Online Organic Store is a web-based e-commerce platform enabling customers to purchase organic vegetables and fruits from home. The system eliminates manual management of customer orders, stock records, and product catalogues — replacing paper-based processes with a digital storefront.

A web-based e-commerce application for buying 
organic vegetables and fruits online. Built as 
part of MCA curriculum at NMAMIT Nitte (Sep 2021).
### 🎯 Objective
Reduce manual work for managing customer details, 
stocks and orders for organic vegetables and 
fruits through a digital platform.
### ✨ Key Features
| Feature | Description |
|---------|-------------|
| 🔍 Product Search | Search organic products by name or category |
| 🛒 Online Shopping | Browse and order vegetables and fruits from home |

| 📦 Order Management | Track and manage customer orders |
| 📋 Stock Management | Monitor inventory of organic products |

### 🏗️ Architecture
```
Customer (Browser)
      ↓
Frontend — Bootstrap + HTML + CSS + JavaScript
      ↓
Backend — Node.js
      ↓
Database — MongoDB
           (customers, orders, products, stock)
```
- **Frontend:** Bootstrap, HTML, CSS, JavaScript
- **Backend:** Node.js
- **Database:** MongoDB
